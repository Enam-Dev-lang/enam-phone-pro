# ENAM PHONE - Lomé PRO 📱
Tableau de bord qui fait gagner de l'argent pour boutiquiers à Lomé.

![Python](https://img.shields.io/badge/Python-3.10%2B-blue)
![Streamlit](https://img.shields.io/badge/Streamlit-Dashboard-red)
![Made in Togo](https://img.shields.io/badge/Made%20in-Togo%20🇹🇬-green)

Solution complète pour gérer boutique de téléphones : Stock, Profit FCFA, IMEI, Rapports PDF.

**Fonctionnalités :**
- Stock temps réel
- Calcul profit auto (ex: +17.000 FCFA / vente)
- Gestion IMEI
- Marques : iPhone, Tecno, Infinix
- 100% offline, sans internet
